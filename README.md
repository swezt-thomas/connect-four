# connect-four
## Overview
Python implementation of Connect Four featuring three game modes: Classic, Custom Grid Size and Blind Mode, developed as part of a first-year undergraduate programming project.
The project focuses on implementing game mechanics, managing player turns and detecting winning conditions.
## Features:
- Detection of full columns and game-ending situations.
- Save ongoing game and resume it later.
- Classic Mode: Traditional Connect Four gameplay on a standard-sized grid.
- Custom Grid Mode: Play on a board with customizable dimensions.
- Blind Mode: A memory-based challenge where players must remember the colors of their own discs, adding an extra layer of difficulty to the game.
